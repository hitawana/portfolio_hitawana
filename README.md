# Portfólio de Hitawana da Silva Araújo

Portfólio profissional com projetos nas áreas de automação de processos, desenvolvimento web e tecnologia educacional.

## Tecnologias

Desenvolvido com React 18, TypeScript, Vite, CSS puro e HTML5 Canvas.

## Execução local

Instale as dependências e inicie o servidor de desenvolvimento:

```bash
npm install
npm run dev
```

Para gerar e visualizar a versão de produção localmente:

```bash
npm run build
npm run preview
```
